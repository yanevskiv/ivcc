Ivan's C compiler toolchain!
----------------------------

SYNOPSIS 
    
    ivcc is a comprehensive C99 compiler toolchian for x86-64 architecture.

        > ivcc  - Compiler driver
        > ivld  - Linker
        > ivas  - Assembler
        > ivemu - Emulator

CONTRIBUTING

    ivcc project is not open to contributions.
